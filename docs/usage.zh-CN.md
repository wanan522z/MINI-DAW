# Mini DAW 详细使用说明

[项目说明](../README.md) | [English](../README.en.md)

Windows 10/11 x64 的 ASIO / VST2 / VST3 麦克风调音台，powered by WanAn522z。

本项目从 Aggregate Audio 驱动工程独立迁出，可单独编译。音色处理全部由加载的效果插件完成，没有自写 EQ、压缩、降噪或限幅。

## 运行

当前可运行版本：`out/MiniDAW.exe`。安装并配置 Aggregate Audio ASIO 驱动后启动程序；首次打开默认 12 条通道，自动选用 `Aggregate Audio`。不提供 WASAPI、DirectSound 或 Windows Wave 后备路径。未安装驱动时界面显示缺少驱动的提示。

Aggregate Audio 由独立项目维护，不需要把驱动源码放进此仓库。使用该驱动时，请运行其安装程序，再通过配套配置程序选择设备声道。

安装版：`dist/MiniDAW-0.2.0-x64-Setup.exe`。Setup 提供安装组件列表，Mini DAW 主程序必选，Aggregate Audio ASIO 可选；首次安装默认推荐两项，已安装 Aggregate Audio 时默认仅安装主程序。包含离线 Visual C++ x64 运行库、开始菜单与可选桌面快捷方式。Aggregate Audio 使用独立项目的完整 v21 安装包，保留独立卸载入口；卸载 Mini DAW 不删除共享驱动、运行库或个人设置。使用其他已有 ASIO 驱动时，可只安装 Mini DAW。执行 `./packaging/build-installer.ps1` 可重新编译主程序并打包，只编译不运行测试，详细参数见 `packaging/README.md`。

## 调音台

插件槽和通道标题不再弹出悬浮操作说明；正常文字及右键菜单保留。

Windows 触屏或触控笔按住通道标题、通道空白处或插件槽约 650 毫秒可打开对应的右键菜单；允许 8 像素轻微抖动，开始拖动或同时使用第二个触点时取消长按。触屏菜单跟随接触位置，菜单行高为 32 像素；抬手不会再触发插件打开、启用开关或预设文件选择。长按“加载预设”显示最近预设。触屏发送旋钮按住约 350 毫秒打开路由菜单，继续保持按住至约 850 毫秒收起菜单并进入浮动拖动；也可用“向上移动发送 / 向下移动发送”调整顺序；鼠标原有长按 550 毫秒浮起拖动保留。通道与插件触屏拖动使用实际手指位置跟随预览及边缘滚动。双击鼠标或双击触屏仍可重命名通道、将发送音量恢复到 0 dB。

调音台横向滚动和插件链纵向滚动使用连续缓动，多次滚轮输入累计距离，直接操作导航条会停止缓动。通道及插件拖动使用带阴影的浮起预览，保持鼠标抓取位置；目标框和插入缝隙有渐变提示，靠近边缘可连续滚动。插件拖起后原位置显示空槽，松手时同一个预览立即吸附落位，移动过程中逐渐过渡到目标槽的颜色和透明度，交接前已呈现最终样式；跨通道复制时源插件轻微虚化淡入，加载在落位后进行；取消或拖到无效位置时从松手位置顺滑回到原槽。发送旋钮左右对称内收，中心对齐相邻行的标题中心，标题保持原有位置。内录通道在 Mute 左侧显示同通道色的小号“内录”字样；Mute 在标题框内的上、下、右边距统一。输入、输出、接收框周围留出默认 10 像素间距，标题下方额外增加 2 像素视觉留白，插件槽之间保持 5 像素，并随通道比例一起调整；默认高度完整展示两行发送旋钮。推子 0 dB 刻度位于第四个插件顶部，+12 至 −36 dB 每 6 dB 等间距，−36 dB 以下逐渐压缩到 −∞；工程音量值不受布局调整影响。滚轮采用连续速度的缓动，起步和停下都平滑过渡；纵向每格滚动半行旋钮。

- 每条通道一个推子，集成立体声电平；左侧刻度 +12 dB 至 −∞，默认 0 dB。点击或双击不改变数值，只有拖动才调整，0 dB 附近有吸附；底端为数字静音。静音按钮位于标题右侧。
- 默认 12 条，通道阵列最右侧“＋”可继续添加，当前最多 32 条。窗口横向加宽显示更多通道；拖软件外框改变高度时，通道贴着底部，插件控件尺寸保持不变。拖动通道右边缘统一调宽全部通道，按住 Ctrl 则只调当前通道。拖通道底边缘同时改变软件窗口及全部通道高度，并调整插件框、输入输出框和发送区的纵向比例；双击对应边缘恢复默认比例。尺寸随工程保存，支持撤销。通道标题与推子固定；第二个旋钮下方 dB 文字能完整显示时，只让旋钮区独立滚动；文字被截断时才让插件链和旋钮一起滚动。各导航条独立在滚动时显示，停止滚动后保留三秒，鼠标悬停导航区域时也显示，细条两侧保留均匀间距。默认窗口为 1059 × 782 外框尺寸。
- 黑色输入栏选择 ASIO 单声道或立体声对，红色输出栏设置直接输出。立体声条目同时显示左右两个端口名，例如“1/2 · Analogue 1 / Analogue 2”。默认不连接直接输出。名称超宽时保持正常字宽并省略，悬停显示完整名称。
- 每条通道有 12 个效果插件槽，支持 64 位 VST2 DLL 和 VST3。空槽不显示文字，已加载插件前显示槽位编号。只有左侧圆点切换启用；单击其余区域打开插件界面，空槽单击打开列表，双击不设独立动作；右键可替换或卸载。同通道拖到插件主体交换位置，拖到槽间隙插入。松手后浮动预览从鼠标的实际位置吸附到目标框，跨通道复制也使用同样的落位动画。落到已有插件上会先确认再替换，源插件保留；侧链菜单显示槽位编号和插件名称，移动时侧链连接跟随插件。
- 启动后后台扫描标准 VST2 / VST3 路径，也可添加并记住自定义目录。缓存立即可用，新增结果逐批加入；显示进度、当前插件和失败文件。VST3 优先读取清单，其他 VST3 工厂及 VST2 实例元数据在最多三个独立进程中探测，单文件超时 15 秒。过滤乐器；通道数未知的效果加载时协商并验证主音频总线。列表按厂商和名称合并重复版本，优先 VST3，再选较新版本；首选加载失败时依次尝试同插件的其他版本。单声道变体、不同厂商和同一工厂的不同类保持独立。缓存保留所有格式，工程还原和复制使用原格式及状态，不跨格式套用参数。
- 默认两个发送旋钮，初始 0 dB，双击回到 0 dB。右键选择目标通道主输入或插件侧链总线，也可选择 Pre-FX / Post-FX，默认 Post-FX；直接拖动设置发送量。鼠标在每次按下后的初始静止阶段可长按 550 毫秒进入浮动拖放，允许 5 像素抖动；触屏按住 350 毫秒打开菜单，持续按住至 850 毫秒进入浮动拖放，允许 8 像素抖动；开始调音量后，本次按住不再判定长按。浮动旋钮连同侧面名称一起拖动，拖到同通道旋钮主体交换位置，拖到旋钮之间的高亮缝隙插入并移动后面的旋钮；拖到其他通道连接主输入发送，支持撤销。每个旋钮侧面的留白居中显示两行文字，第一行为 A/B/C 等编号及目标通道编号，第二行为名称；旋钮上下间距紧凑，dB 数值以较小的低亮度文字紧贴圆弧下方。旋钮为 270° 圆弧，最低左下、最高右下。第二个旋钮连接后自动出现第三个，后续依次增加；按可用空间独立滚动或随插件链一起滚动，颜色跟随目标通道。
- 发送旋钮上方“接收”下拉栏展示来源，菜单列出主输入及“槽号 · SC 总线编号 · 插件总线名称”。发送旋钮缩小并左右交错排列，推子沿通道高度伸展。SC 1 对应插件输入总线索引 1，主输入索引为 0；只提供插件实际声明且启用的总线。
- 拖动标题到其他通道主体交换两个通道，到通道间隙则插入移动；路由随通道保留。标题前保留位置编号，改名不影响编号。通道条或标题右键可复制、粘贴和打开完整调色盘（HSV、RGB、精确色值和 24 个快捷色）；首次加载插件时自动分配通道颜色。复制包括插件状态、推子、静音、设备绑定、颜色和发送；粘贴会跳过无效或反馈连接。
- 默认内容尺寸为 1059 × 751，所有内容直接渲染，输入、输出和接收栏文字保持正常字宽，超长时省略。控件框采用相同圆角，标题围绕通道色描边，不显示顶端色线或 INPUT / OUTPUT 字样。状态信息以小字放在 Logo 下方，顶部按钮保持单行；撤销、重做箭头使用较小尺寸。应用、窗口及托盘使用与 ASIO 同风格的三条斜线图标。
- 顶部 ↶ / ↷ 按钮和 Ctrl+Z、Ctrl+Y（或 Ctrl+Shift+Z）支持撤销/重做最近 32 次宿主操作，包括通道及插件的排列、复制、替换、删除、颜色、绑定、发送、静音和音量。一次拖动为一条历史；保留插件实例以恢复被替换的插件及参数。插件自身原生界面内的参数编辑使用插件自身撤销机制，加载项目时清空宿主历史。
- 插件原生标题栏“？”按钮打开 Settings（系统菜单也有入口）。支持设置窗口宽高、DPI 缩放和每个侧链总线的来源通道或“无”。尺寸和缩放按插件支持能力生效，设置随项目保存。
- 进入 DAW 自动启动所选 ASIO。顶部设置图标打开独立小窗口，分为 ASIO 设置、插件扫描设置、内录设置、作者信息和 GitHub 链接。ASIO 页可选择驱动、采样率与缓冲区，启动/停止音频并打开驱动控制面板；插件页可编辑扫描目录、添加目录、恢复默认路径、开始或停止扫描。内录页为每个 ASIO 输出端口指定对应的 Windows 输出设备和声道，可刷新设备、使用自动匹配或仅采集宿主；映射随工程保存，支持撤销。监听驱动重置和通道列表变化，并在回调中断时重试重建；按驱动、名称及同名出现次序保存设备绑定；设备断开时保留名称并显示“未连接”，重新接入后自动恢复，不会按旧编号切换到其他设备。断开时保存预设、复制通道或撤销操作仍保留原绑定；手动选择其他设备或“无”会更新或清除这项绑定。重新接入若与断开期间的路由编辑形成反馈环路，保留名称并暂停冲突的连接。
- 顶部“保存预设 / 加载预设”保存或加载 `.minidaw` 项目文件，包括所有通道、插件状态、路由、颜色、窗口设置和设备通道身份；无效文件不会替换当前工程。悬停“加载预设”450 毫秒或右键时显示最近打开的 12 个预设，点选切换；普通单击打开 Windows 文件选择器，最近预设菜单展开时也可直接单击按钮。文件选择器以主窗口为父窗口，并从当前预设的位置开始。列表按最近使用排序并去重，重启后保留，失效路径禁用，同名预设显示所在目录。
- 任意通道右键可“转为内录通道”，保留插件和发送，清空原有输入输出绑定，需重新分配。内录输入完整列出当前 ASIO 驱动的全部输出端口；可挂 VST2 / VST3 插件并使用发送。宿主写给该输出的声音与对应 Windows 输出的系统声音合并后进入内录插件链。Aggregate Audio 使用 KS 输出，系统回送与宿主分开采集；按唯一设备名称及完整声道组自动匹配，名称截断、声道子集或多个同名设备无法确定时，在“设置 → 内录设置”中手动指定每个端口对应的 Windows 设备和声道。其他 ASIO 驱动需手动映射；如果回送已包含宿主，取消“合并宿主输出”以避免重复。只为已选择的内录来源启动系统回送，同一 Windows 设备只采集一次；系统回送使用独立线程和预分配缓冲，并转换为当前 ASIO 采样率。它包含 Windows 音频引擎的播放内容；设备独占播放、硬件自身监听或硬件 DSP 混音能否被采集取决于设备提供的回送能力。ASIO 处理仍使用原驱动，Windows 回送会有额外的采集延迟。输出选择 ASIO 输入绑定，将处理后的信号混入 Mini DAW 内使用该输入的普通通道，位于其插件之前；禁止形成宿主反馈环路。工程中遗留的全局回送映射会被忽略。旧工程的内录输入采用旧语义，升级后清空这项绑定以便重新选择输出，保留插件、发送和输出跳线。转换模式及绑定随工程保存，支持复制和撤销；切回普通通道时也清空设备绑定。系统虚拟设备创建功能已取消，程序不安装新驱动或修改签名设置。

内录通道的输入菜单分为“ASIO 设备”和“Windows 输出”。ASIO 组列出驱动的输出端口，继续支持宿主输出与系统回送合并。Windows 组直接列出可共享的 Windows 播放设备及其单声道、立体声对，排除当前 ASIO 已占用的对应设备和无法共享打开的输出；此来源不要求在 ASIO 控制面板中勾选对应设备。用于 Windows 播放的普通耳机或扬声器应从 ASIO 配置中取消勾选，再从 Windows 组选择；ASIO 引擎仍需使用其余可用设备正常运行。若需要同时采集宿主声音，将相应宿主通道发送到这条内录通道。菜单提供“刷新 Windows 输出设备”，设备身份及声道随预设、复制和撤销保存；失效选择保留原设备名称及声道并显示“未连接”，不会替换成其他设备；监听 Windows 设备变化并自动刷新，原设备恢复可用后自动连接。内录设置中的端口选择按名称保留，端口顺序变化不会切换到其他端口。

Windows 系统回送跟随所选输出设备的 Windows 主音量和静音；音量为零时内录的系统声音也静音。使用设备报告的 dB 音量换算增益，并以 5 毫秒平滑过渡；音量控制查询在采集线程执行。此增益只作用于系统声音，合并后的整体音量继续由内录通道推子控制。设备无法提供音量控制接口时，内录设置显示“无法读取系统音量”。

自动设备刷新只处理连接状态、名称和音频格式变化，忽略默认播放设备及无关属性通知；Windows 通知不直接重启 ASIO。自动枚举在后台执行，列表未变时不重建界面，也不对已识别的 ASIO 占用输出尝试共享打开。ASIO 仅在驱动请求重置、通道布局实际变化或音频回调中断时重建。

Post-FX 发送位于插件链和推子之后；Pre-FX 发送使用源通道插件之前、推子之前的信号。两者均受通道静音控制，并可混入目标主输入或指定插件的侧链。路由按拓扑顺序处理，禁止形成反馈环路。沿用 ASIO 控制面板的当前采样率，设置小窗口可选驱动支持的采样率和块长并随项目保存。状态显示驱动报告的输入 + 输出延迟，悬停可查看已连接输出路径的最大插件延迟。宿主不额外排队音频块；回调只清空当前块，使用预先计算的路由列表并抑制浮点非正规数。目前没有插件延迟补偿、多轨录音或播放时的插件进程隔离（扫描使用独立进程）。实际延迟需要在相同驱动、采样率、块长和插件设置下比较，驱动报告值不是物理回环测量。

关闭窗口提示“保存并关闭 / 不保存关闭 / 取消”；点击“后台驻留”会保留音频处理；双击托盘恢复，右键保存并退出。工程和插件状态保存于 `%APPDATA%/MiniDAW/session-v2.xml`，插件列表缓存为同目录的 `effects-vst3.xml`。迁移项目目录不会修改这些个人设置。

## 编译与测试

需要 Visual Studio 2022 C++ 工具链、Windows SDK、CMake 3.24+ 和 Git，目标架构 x64。

VST2 宿主还需要 SDK 的 `pluginterfaces/vst2.x/aeffect.h` 和 `aeffectx.h`；默认查找 `vendor/vst2-sdk`，也可用 `-DMINIDAW_VST2_SDK=你的SDK目录` 指定。接口头文件不随仓库提交。

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --target mini_daw mini_daw_routing_test --parallel 4
ctest --test-dir build -C Release --output-on-failure
```

也可执行 `./tools/build.ps1`，自动查找 Visual Studio 的 CMake，完成构建与测试，并更新 `out/MiniDAW.exe`；如果当前程序正在运行，会保留会话并把新构建保存为 `out/MiniDAW-next.exe`，退出当前程序后再替换。构建输出位于 `build/mini_daw_artefacts/Release/MiniDAW.exe`。

JUCE 8.0.12 固定提交 `29396c22c93392d6738e021b83196283d6e4d850`。迁移时保留了 `third_party/JUCE` 本地源码并忽略其 Git 提交；全新克隆缺少该目录时，CMake 会从官方仓库获取固定版本。此工程使用 JUCE 的 ASIO / VST2 / VST3 宿主实现，不依赖原 `asio` 文件夹或外部 ASIO SDK 路径。

默认测试不打开麦克风。路由测试覆盖 0 dB、−∞、+12 dB、拓扑顺序、反馈环路和发送旋钮增长；宿主测试验证发送、输出映射、静音、不同块长、复制替换、撤销重做及侧链保留；界面测试验证实际拖放命中区域、推子手势和横向/纵向排版。真实插件拖放验证会自动取消和确认替换对话框，检查取消不改动及确认后可撤销。
